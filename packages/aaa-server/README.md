# aaa-server

HTTP/SSE server for [AAA](https://github.com/innerkorehq/AutonomousAgentAlgos) agents: authentication, tenant isolation, rate limits, quotas and approvals.

See the [server guide](https://innerkorehq.github.io/AutonomousAgentAlgos/guides/server/) and the [threat model](https://innerkorehq.github.io/AutonomousAgentAlgos/security/server/).
