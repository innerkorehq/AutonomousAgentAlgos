# orders

An MCP server generated by `aaa mcp init` (aaa 0.3.1). The configuration is `server.json`: edit it, then check what it exposes.

```bash
pip install -r requirements.txt
aaa mcp check   --config server.json     # validate, compile, report what is exposed and what is hidden
aaa mcp inspect --config server.json     # print exactly what a client (and its model) will be shown
aaa-server serve server:build --host 127.0.0.1 --port 8000
```

Set `MCP_API_KEYS='{"<api key>": ["<tenant>", "<subject>"]}'` to say who may call it. The key decides the tenant and user.

`server.py` and the other generated files carry no logic of their own; `aaa mcp export --check .` tells you if one has drifted from its
template and `aaa mcp export --update .` regenerates the ones you have not edited. Secrets are read from the environment (see `.env.example`);
never put a value in the configuration.
